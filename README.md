Airbnb Open Data Analysis

This repository contains a Python Jupyter Notebook for advanced analysis and visualization of Airbnb Open Data.The project allows users to explore, clean, and visualize large Airbnb datasets, helping in understanding important trends in pricing, reviews, and room distribution.

Features:

Automatically loads and handles both Excel and CSV Airbnb datasets.
Cleans data (removes duplicates, handles missing values, corrects numeric fields).
Visualizes price distributions, top neighborhoods by price, room type distributions, and review trends using Matplotlib and Seaborn.
Provides correlation heatmaps to understand relationships between variables.
Step-by-step analysis for price, reviews, and availability.

Requirements:

Python 3.x
Jupyter Notebook/Google Colab
Pandas
NumPy
Matplotlib
Seaborn
scikit-learn (for some regression/modeling tasks)
openpyxl (for Excel file support)

Output:

The notebook generates visualizations such as:
Airbnb price distributions
Top neighborhoods with average prices
Room type distributions
Correlation heatmap across variables
Price vs. number of reviews scatterplots
